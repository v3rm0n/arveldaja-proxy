Balances carried into e-arveldaja when bookkeeping was started there (e.g. share capital paid in earlier). They live in a hidden "INITIAL" journal that the e-Financials API omits from listings, so the proxy stores them locally and adds them on top of journal-based balances. Use Detect to find that journal automatically (or pass its ID if you know it), or add rows manually. Positive = debit balance (assets), negative = credit balance (equity/liabilities); a complete set sums to zero.
